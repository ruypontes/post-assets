# post-assets

Images that accompany posts on [linkedin.com/in/drruinobrega](https://www.linkedin.com/in/drruinobrega).

## cards/

Source cards. Each one carries the journal, the authors, the year, the measured
figure, and the DOI of the paper the post discusses.

These are **not** journal cover art. Publisher artwork is copyrighted, and of the
sources referenced here several are CC BY-NC-ND, which forbids derivative use.
The cards therefore carry only facts, which are not copyrightable, and credit the
source in full so the reader can go and check it.

Generated from `linkedin-action-pack/infographics/source-card/` (data-driven,
Playwright render). Palette and type follow the same editorial system as the
timeline charts.
